# Scottbet Agent

עמוד נחיתה ל-Scottbet (אתר בלי סוכנים): וידאו פתיחה, שישה משחקי דמו (גלגל המזל, מכונת מזל, קראש, פלינקו, פנדל, כרטיס גירוד) וכפתורי פעולה לפלטפורמה.

## הרצה

```bash
npm install
npm run dev
```

## בנייה לפריסה

```bash
npm run build
```

התוצאה בתיקיית `dist/` (אתר סטטי, מתאים לכל אחסון).

## קישורים

כל הקישורים נמצאים ב-`src/site-config.ts`: לינק ההפניה לפלטפורמה, מספר וואטסאפ וטלגרם. כפתורי וואטסאפ וטלגרם מופיעים רק אחרי שממלאים את השדות.

משחקי הדמו פועלים עם מטבעות דמו בלבד, ללא כסף אמיתי.
